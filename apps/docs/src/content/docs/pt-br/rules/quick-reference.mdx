## Tente Qualquer Coisa!

O Mestre define a dificuldade. Se você tentar novamente, use 1 nível de Esforço.

**Recursos (2 passos):** Um item útil, uma ajuda ou uma circunstância favorável.

**Esforço (6 passos):** Custa 3 pontos de Reserva + 2 pontos por nível adicional.

## Pagando Custos

Custo total da reserva, subtraia a margem.

## Movimento

**Imediata:** realizar uma ação

**Curta:** ação; tarefa de Velocidade (dificuldade 4) para outra ação

**Longa:** tarefa de Velocidade (dificuldade 4)
