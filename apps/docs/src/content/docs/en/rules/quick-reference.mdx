## Try Anything!

The GM sets the difficulty. If you retry, use 1 level of Effort.

**Assets (2 steps):** A useful item, help, or favorable circumstance.

**Effort (6 steps):** Costs 3 Pool points + 2 points per additional level.

## Paying Costs

Total Pool cost, subtract Edge.

## Moving

**Immediate:** take an action

**Short:** action, difficulty 4 Speed task for another action

**Long:** difficulty 4 Speed task
